# 🎂 3D 颗粒生日蛋糕

一个纯前端、零构建依赖的 3D 生日蛋糕页面：整只蛋糕由 **上万颗彩虹粒子** 堆叠而成，
悬浮在程序生成的 **宇宙星云** 中，搭配彩色糖粒、奶油糖霜、蜡烛火焰、漂浮星尘与吹蜡烛时的彩纸喷发效果。

## 技术栈

- [Three.js](https://threejs.org/)（`0.160.0`，通过 CDN + `importmap` 引入，无需 `npm install`）
- 原生 ES Module，无打包工具

## 如何运行

直接双击打开 `index.html` 即可（需要联网加载 Three.js CDN）。

如果浏览器因 `file://` 协议限制导致异常，用任意静态服务器启动：

```bash
# 方式一：Python
python -m http.server 8000
# 方式二：Node
npx serve .
```

然后访问 `http://localhost:8000`。

## 交互

| 操作 | 效果 |
| --- | --- |
| 拖拽 | 旋转视角 |
| 滚轮 | 缩放 |

## 实现要点

- **蛋糕颗粒**：三层圆柱，每层按“角度 → 彩虹色（HSL）”渐变上色并逐层偏移色相/亮度，
  在侧面与顶面按密度撒点，形成炫彩的“颗粒”质感（`Points` + `vertexColors`）。
- **糖霜与糖粒**：顶部一圈珠光彩虹奶油滴落 + 六色 funfetti 糖粒散落表面。
- **火焰**：`Sprite` + 径向渐变贴图 + 加法混合，逐帧做双重正弦闪烁。
- **彩纸粒子**：吹蜡烛时从蛋糕顶部喷出 600 颗彩色粒子，带重力、落地回弹与寿命衰减。
- **氛围**：程序生成的宇宙星云天空球（多彩星云团 + 繁星，缓慢旋转）+ 金色漂浮星尘 + 暖色点光源随火焰呼吸。
